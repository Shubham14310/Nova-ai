Nova AI Prompt Guide

Practical ways to ask clearer questions · Updated November 19, 2026

A useful AI response often starts with a clear request. You do not need complicated wording. Explain the task, add the context that matters, and say what the final answer should look like. These examples are starting points; adapt them to your own question.

1. A simple prompt structure

  1. Task: say what you want the assistant to do.
  2. Context: include the topic, audience, or details that change the answer.
  3. Format: ask for steps, a short paragraph, a table, or examples.
  4. Limits: mention the level of detail or language you prefer.
Example: “Explain photosynthesis for a beginner in simple language. Use five numbered points and include one everyday example.”

2. Improve a vague question

A short question can work, but adding a goal helps the assistant understand what you need.

Instead of: “Tell me about computers.”
Try: “Explain the difference between RAM and storage for someone new to computers. Give one example of when each is used.”

3. Ask for learning help

When studying, name the exact topic and your current level. Ask for an explanation, worked example, or a way to check your understanding. If you only want a hint, say so clearly.

Example: “Explain how to identify the subject and predicate in a sentence. Show two original examples, then give me one practice sentence.”

4. Ask questions about an image

If image upload is available in your installed version, attach the image and ask about something specific. Mention whether you want a description, a comparison, or help reading visible information. Results may be less reliable when an image is blurry, cropped, or contains very small text.

Example: “Describe the main objects in this picture. Then tell me which details are clear and which parts are too blurry to identify confidently.”

5. Work with a PDF

Where PDF upload is supported, attach the document and ask a focused question. For a long document, begin with a summary and then ask about one section at a time. Ask the assistant to distinguish what the document says from any explanation it adds.

Example: “Summarize the attached PDF in six bullet points. Mention the section heading for each point, and say if any page is unreadable.”

6. Request a useful format

You can ask for a response that is easier to use. Examples include:

  • “Give me a short answer first, then explain why.”
  • “Compare these choices in a table with advantages and limitations.”
  • “Rewrite this paragraph in clear, polite language without changing its meaning.”
  • “List the steps in order and explain any unfamiliar terms.”

7. Refine an answer with follow-up questions

If the response is too long, ask for a shorter version. If a point is unclear, quote that point and ask for a simpler explanation. If the answer appears incorrect, explain what seems wrong and ask the assistant to review its reasoning. A confident tone does not prove that an answer is correct.

8. Protect your privacy

Do not include passwords, one-time verification codes, payment details, identity numbers, private addresses, or confidential documents in prompts. Only upload images and files you have permission to share. Be especially careful with personal information about other people.

9. Check important information

AI responses can contain mistakes, missing context, or outdated information. Verify important facts with reliable sources. Do not use AI as the only basis for medical, legal, financial, or safety decisions.

Feature note: Image, PDF, and voice tools depend on the app version and service availability. If a feature is not shown in your app, check the Help & User Guide or the latest release notes.
